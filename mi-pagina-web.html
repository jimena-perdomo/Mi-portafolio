PROYECTO 04 · DESARROLLO WEB

Mi página web

Una página web que comenzó como una asignación escolar y terminó convirtiéndose en una experiencia para aprender a programar desde cero.

¿DE QUÉ TRATA?

Es una página web sencilla que presenta datos clave de una serie o película de mi elección. En este caso, el tema fue Game of Thrones.

¿QUÉ APRENDÍ?

Aprendí a construir una página utilizando HTML y CSS. Aunque al principio algunas partes me resultaron difíciles, el proceso me enseñó que la paciencia y la perseverancia son importantes cuando queremos dominar algo nuevo.

HERRAMIENTAS

HTML, CSS y Visual Studio Code.

RECORRIDO POR LA PÁGINA

Un vistazo a sus secciones

La página presenta información sobre las casas y algunos de los personajes principales de la serie.
