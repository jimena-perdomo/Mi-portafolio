# Portafolio de Jimena Perdomo

## Estructura
- `index.html`: Inicio
- `sobre-mi.html`: Sobre mí
- `proyectos.html`: índice de proyectos
- `munch-spot.html`: caso de estudio MunchSpot
- `pot-c.html`: caso de estudio Pot-C
- `contextos.html`: caso de estudio Contextos
- `mi-pagina-web.html`: caso de estudio de la página web
- `contacto.html`: Contacto
- `css/style.css`: estilos globales, composición y responsive
- `js/main.js`: aparición progresiva y transición de navegación
- `assets/images/`: coloca aquí las fotografías y evidencias originales

## Base visual
- Lienzo de referencia Figma: 1440 × 1024 px
- Colores: crema `#f8f3ee`, vino `#713f4a`, rosa `#d8a7a7`, tinta `#403337`
- Tipografías: Bodoni Moda y Montserrat

## Cómo visualizar
Abre `index.html` en un navegador. Para una experiencia local más fiable, abre la carpeta con VS Code y utiliza una extensión de servidor local.

## Imágenes
Los recuadros con la leyenda “ESPACIO PARA…” son marcadores provisionales. Sustitúyelos por las imágenes y evidencias originales cuando estén listas. No se incluyeron fotografías inventadas.
